## The vow

> I vow to love you through every firmware update, every dead battery, and every reboot, and to never, ever factory-reset us.

(123 characters, one line.)

## Run it

```sh
node main.ts
```

`main.ts` writes the vow to `/output/entry.txt`. Nothing else.
